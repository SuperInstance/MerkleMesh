# MerkleMesh

MerkleMesh enables distributed real-time data aggregation and validation through a self-healing network tree architecture.

MerkleMesh is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- MerkleMesh enables distributed real-time data
- aggregation and validation through a
- self-healing network tree architecture

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/MerkleMesh.git`
2. `cd MerkleMesh`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
